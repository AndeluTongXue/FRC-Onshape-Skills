# Onshape UI shortcuts & behaviors (Onshape Help)

Context matters: same key differs in sketch vs part studio vs assembly.

## General / view
Alt/⌥+C tool search · S shortcut toolbar · Shift+/ shortcut list · Enter accept · Shift+Enter accept & repeat · Esc exit · Space deselect · Ctrl+Z/Y · ` pick-under-cursor · Alt/⌥+T tab manager · Shift+1…7 standard views · N normal to · F fit · Shift+X section view · P planes · Shift+P hide construction · arrows rotate 15°.

## Sketch
L line · G corner rectangle · R center rectangle · C circle · A 3-pt arc · Shift+S point · Q construction · U use/project · O offset · M trim · X extend · Shift+F sketch fillet · D dimension.
Constraints: I coincident · Shift+O concentric · B parallel · T tangent · H horizontal · V vertical · Shift+L perpendicular · E equal · Shift+M midpoint · Shift+K normal · Shift+G pierce · Shift+Q symmetric · Shift+J fix.
Hold Shift to suppress inference. Blue = under-defined, black = fully defined, red = over-constrained. Right-click dimension → Driving/Driven.

## Part Studio
Shift+E extrude · Shift+W revolve · Shift+F fillet · Shift+H show/hide sketches · ↑/↓ move rollback bar · right-click feature → Suppress / Roll to here / Add to folder · Shift+N rename (default; teams often rebind).
Regeneration times: clock icon in Feature list.

## Assembly
I insert · M fastened mate · J show/hide mates · K show mate connectors · Shift+S snap mode · A flip primary axis (in mate dialog) · Ctrl+M mate connector · Y hide · Shift+I isolate · Shift+T transparent · Shift+Y show all.

## Performance (browser)
cad.onshape.com/check; Chromium browsers best; enable hardware acceleration; try ANGLE backends in chrome://flags.
